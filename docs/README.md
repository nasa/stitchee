## Quick Start

**Developers:** Feature branches → merge to develop → CI handles versioning

**Releases:** Create release branch → CI auto-bumps → test → merge to main

**Hotfixes:** Branch from main → fix → merge → merge back to develop

All version management is automatic. See [VERSIONING.md](VERSIONING.md) for details.
